# 财务问数Agent：密钥与真实API测试约定

本约定来自用户2026-10-17的明确要求，适用于本目录及其子目录。

- 每次由助手发起使用真实API Key的请求之前，必须先与用户核对并得到本次明确确认。说明目的、接口/模型、发送的数据范围以及本次只发送1个请求。
- 一次确认不覆盖下一次请求、第二个模型步骤、重试、连通性探测或余额/模型验证。需要第二次请求时重新确认；禁止自动重试。
- 未经确认，只能进行不会访问外部模型服务的测试，使用模拟模型或本地模板；不得为了检查配置而读取、打印或尝试真实Key。
- 不在终端、聊天、日志、截图、异常或Git差异中显示Key，不将真实Key写入源代码、示例、测试或提示词。
- Key默认放在secrets/deepseek_key.txt，仅由应用后端按配置读取；config.local.json、secrets/和runtime/不得提交。
- 用户自行在网页提交正常业务查询不属于助手发起的测试；助手通过浏览器或脚本发起查询仍属于助手测试，配置真实Key时须遵守逐请求确认要求。
- 提交/上传前检查忽略规则及Git已跟踪文件。gitignore不会取消已跟踪文件，也不能从历史提交中移除泄露Key；发现真实密钥已提交时先告知用户并建议撤销/轮换，不自行重写Git历史。
- 不因本约定自动上传项目或业务数据；保留现有财务资料忽略规则。
