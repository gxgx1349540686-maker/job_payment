- 我方应收为T06-1登记基准，调整单列；租客应收为账单费用登记。净应付、未收未付余额及分项核销仍不能自动计算。

- 尾期来源可展开到原工作表实际行号；其他指标先追溯到业务表和记录ID，不宣称全部已有原Excel行号。
- 本机网页已经实现，未部署网站；网站化需额外建设认证、项目权限和私有数据连接。
