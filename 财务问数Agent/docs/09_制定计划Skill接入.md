# 制定计划Skill接入 0.3.1

2026-10-20。本轮按用户要求接入现用财务问数Agent，前端提示“制定计划”。

## 已实现

应用PlanSkills加载skills/payment-plan-reconcile/skill.json与SKILL.md，校验注册名、处理器和工具列表，按Pydantic契约拒绝额外参数，执行四个具名固定工具。说明格式由已确认规则加载，不依赖Codex自身技能系统。
首页与功能菜单入口打开表单；输入楼栋、支付月份、结算核对月份，可选合同。前端调用/api/plans/options、/api/plans/check；聊天中“制定计划”也路由到该入口，不调用模型。
只读T07计划、T01历史合同收款候选、T08-2_失败单据。账号仅回传末四位。月份分开；历史失败不等于退票；合同不自动认定当前执行合同。
选择合同后可生成已确认尾期说明格式的草稿。金额无有效核验引用时保持未知，输出needs_review，无批准或付款动作。
任务保存于runtime/payment_plan_tasks，提供/api/plans/tasks/{task_id}恢复结果；数据库或规则指纹变化后旧任务标stale。已完成结果可恢复，不代表实现长任务逐步骤断点续跑或复核回流。

## 未完成与边界

这是本地确定性只读核对，不是完整ReAct资金计划。尾期已核验结果引用与金额接入、合同采用时点、附件内容检查、申请归属日期、完整支付批次导出、人工确认回流尚未实现。未通过的前置条件明确列为待核，不用T08月度金额或差额替代尾期金额。未修改数据库、Excel、正式入口、密钥或本地配置。
