# API Key本地保存与测试授权

用户约定日期：2026年10月17日。

## 填写方法

1. 用本机文本编辑器打开`secrets/deepseek_key.txt`，只粘贴一行真实Key并保存。
2. 不加`api_key=`、引号、JSON括号、说明文字或额外行。不要把Key粘贴到聊天、网页问题框或代码文件。
3. `config.local.json`只填写路径：`"api_key_file": "secrets/deepseek_key.txt"`。当前示例默认已是这个相对路径；路径相对Agent目录。
4. 重启服务。Key由后端读取，不放入HTML或JavaScript。不要用会把文件内容打印到终端的方式检查Key。

这是本地明文文件保存，不是加密密钥库。`.gitignore`仅控制Git默认收录行为，不能阻止本机有读取权限的程序访问，也不能替代磁盘权限保护。后续网站部署应使用服务端密钥管理，不把TXT加入部署包。

## Git忽略范围

Agent目录排除`secrets/`、`config.local.json`、`runtime/`、`.env`及常见Key文件名；财务项目根目录另有明确路径保护。真实Key文件和本地配置仅留本机。

提交到GitHub前可以运行`git check-ignore -v -- 财务问数Agent/secrets/deepseek_key.txt 财务问数Agent/config.local.json`核对；这个命令只显示匹配的忽略规则，不显示Key内容。

已经被Git跟踪的文件不受新增忽略规则保护；若密钥曾提交或推送，必须撤销/轮换密钥，不能仅删除文件或补一条忽略规则。不得把“当前未跟踪”说成“全部历史已审计”。

本次只配置忽略和测试约定，不上传项目，也不改变原有业务数据库和资料的忽略范围。

## 助手逐请求确认

每次由助手使用真实Key请求外部API之前，先说明目的、接口/模型、要发送的数据范围、请求次数，并等待用户明确确认。本次最多授权1个请求，第二个请求、重试或其他探测必须重新确认。

应用SDK自动重试已关闭，防止一次操作隐含发送多个请求。默认完整问数链路可能包含“意图解析”和“SQL生成”两个模型请求；助手不能把一次笼统的“测试一下”当作两次调用的授权。

未获确认时，助手只运行本地模板或模拟模型测试，不检查真实Key内容，也不自动执行真实连通性测试。该助手行为约定写入项目AGENTS.md，不是网页逐次弹窗功能。
