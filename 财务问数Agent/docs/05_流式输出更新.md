# SSE流式输出更新

更新日期：2026年10月17日。

网页现使用`POST /api/chat/stream`，通过HTTP响应体持续接收SSE事件。原`POST /api/chat`接口保留，兼容原有非流式调用；没有新增依赖，也不改变DeepSeek每请求确认约定及禁止自动重试配置。

## 用户可见行为

- 建立连接后立即显示处理状态。
- LangGraph每个节点开始、结束时推送真实进度：理解、口径楼栋核对、规则检索、SQL生成、校验、取数及组织答案。
- 财务结果计算并校验完成后，答案文字按段发送，再展示完整表格、选项、规则和来源。
- 查询按钮在处理中变为“停止接收”。停止会断开本次连接并阻止后续节点继续执行；已经发出的模型请求无法撤回，仍可能产生费用，但不会自动重试。
- 连接中断、非法输入或错误会明确提示，不自动重复查询；不将未完成结果标为成功。

## 流式范围说明

本次实现“阶段进度实时推送＋已校验答复分段传输”。当前答案仍由程序根据数据库结果组织，没有额外增加总结模型调用，也没有将DeepSeek的原始Token、未完成JSON、SQL片段或推理过程直接展示为财务答案。由于答案先完成校验，最终文字分段事件可能很快到达；没有添加人为打字延时。

## 事件协议

| 事件 | 内容 |
|---|---|
| connected | 已建立连接 |
| session | 会话ID，便于继续选择 |
| progress | 当前节点、名称、开始/完成状态；不包含模型输入或SQL内容 |
| answer_start | 开始传输已组织的答复 |
| answer_delta | 一段已校验的文字 |
| result | 完整结构化结果、候选、表格及来源 |
| done | 当前请求完成，或等待用户确认 |
| error | 本轮错误；不返回内部SDK错误细节 |

空闲时发送心跳，后台队列有容量上限；客户端断开时设置取消标志。前端以UTF-8流式解码，处理跨网络分块的中文、SSE帧和CRLF分隔符。
